# A股 520 均线分析系统 - 功能设计文档

## 1. 功能总览

系统面向 A 股散户投资者，提供基于 5/20 日均线策略的辅助分析工具。核心功能分为五大模块：

| 模块 | 功能 | 面向用户 |
|---|---|---|
| 股票搜索与自选股 | 搜索股票、管理自选列表 | 所有用户 |
| 策略分析 | 趋势判断、买卖信号、仓位建议、风险评估 | 所有用户 |
| K 线图表 | 可视化行情与信号标记 | 所有用户 |
| 回测验证 | 历史数据模拟交易，验证策略效果 | 进阶用户 |
| 金叉筛选 | 全市场扫描找到金叉股票 | 选股用户 |
| 系统配置 | 数据源优先级、复权方式、Token 配置 | 运维用户 |

## 2. 模块一：股票搜索与自选股

### 2.1 股票搜索

**入口**：首页左侧顶部搜索框

**用户操作流程**：
1. 用户在搜索框输入股票代码或中文名称（支持模糊匹配）
2. 系统自动在 300ms 防抖后发起请求
3. 下拉列表展示匹配结果：`代码 - 名称`
4. 用户点击某一条结果，系统自动执行：
   - 添加到自选股（如果已存在则忽略）
   - 立即对这只股票进行策略分析，右侧展示分析结果

**数据源优先级**：东方财富 suggest API → AKShare 实时行情 → 本地数据库

**边界情况**：
- 搜索无结果：下拉列表为空
- 输入为空：不展示任何结果

### 2.2 自选股管理

**入口**：首页左侧"自选股"列表

**功能列表**：

| 功能 | 操作 | 说明 |
|---|---|---|
| 查看自选 | 页面加载自动展示 | 按添加时间倒序排列 |
| 分析股票 | 点击每项后的"分析"按钮 | 右侧加载该股票的策略分析 |
| 删除自选 | 点击删除图标 → 确认弹窗 | 从自选列表中移除 |
| 刷新列表 | 添加/删除后自动刷新 | 通过 `refreshKey` 机制触发 |

**边界情况**：
- 自选股为空：显示"暂无自选股，请搜索添加"提示
- 重复添加：接口返回 `status: "exists"`，前端提示"已在自选股中"

### 2.3 自选股近 3 天信号

**入口**：首页左侧"自选股近3天信号"卡片

**功能描述**：
- 自动遍历所有自选股，检测近 3 天内产生的买卖信号
- 按股票分组展示，每只股票显示近期的信号标签（彩色）
- 信号类型一目了然：金叉(红)、回踩(蓝)、粘合(金)、MACD+(紫)、止损(橙/红)、死叉(绿)

**刷新**：支持手动点击"刷新"按钮重新加载

**边界情况**：
- 无任何信号：显示"暂无信号"
- 数据拉取失败：显示空列表

## 3. 模块二：策略分析

### 3.1 触发方式

选中一只股票后（通过搜索或自选股点击），系统自动加载分析，右侧展示分析结果。

### 3.2 分析内容

#### 3.2.1 基本信息

| 字段 | 说明 |
|---|---|
| 股票代码 | 如 000001 |
| 股票名称 | 如 平安银行 |
| 最后交易日 | 数据中最新交易日 |
| 收盘价 | 最新收盘价格 |

#### 3.2.2 趋势判断

基于 MA20 斜率判断中期趋势：

| 趋势 | 判定条件 | 描述 | 图标 |
|---|---|---|---|
| 上涨 | MA20 斜率 > 0.5% | 20日线向上，趋势偏多 | 红色箭头↑ |
| 下跌 | MA20 斜率 < -0.5% | 20日线向下，趋势偏空 | 绿色箭头↓ |
| 横盘 | -0.5% ≤ 斜率 ≤ 0.5% | 20日线走平，趋势待变 | 黄色横杠— |

#### 3.2.3 买卖信号

系统检测 10 种信号类型，按触发时间排列：

| 信号类型 | 含义 | 颜色 | 优先级 |
|---|---|---|---|
| 金叉买点 (golden_cross) | 5日线上穿20日线，可能放量+趋势向上+站上均线 | 红 | 核心买入 |
| 回踩买点 (pullback) | 金叉后缩量回踩20日线，带量站上5日线 | 蓝 | 核心买入 |
| 均线粘合 (convergence) | 5/20日线间距缩小后放量发散突破 | 金 | 辅助买入 |
| MACD+买点 (macd_plus) | MACD 由负转正，零轴上方确认 | 紫 | 辅助买入 |
| 金叉+MACD+共振 (combined_gc_macd) | 5日内金叉与 MACD+同时出现，强买入信号 | 粉 | 最强买入 |
| 止损(跌破MA5) (stop_loss_ma5) | 连续3日收盘跌破5日线（价格低于买入价） | 橙 | 卖出 |
| 止损(放量破MA20) (stop_loss_ma20) | 放量跌破20日线 | 红 | 卖出 |
| 死叉卖出 (death_cross) | 5日线下穿20日线，强势趋势结束 | 绿 | 卖出 |
| 最小止盈 (take_profit_mini) | 盈利3%~5%时收盘价跌破MA20 | 粉 | 卖出 |
| 常规止盈 (take_profit_normal) | 盈利10%~20% | 粉 | 卖出 |

**信号表格**：支持按类型筛选、日期排序（默认最新在前）

#### 3.2.4 仓位建议

综合趋势方向和当前信号，给出仓位建议：

| 场景 | 建议仓位 | 说明 |
|---|---|---|
| 20日线向下 | 0%（空仓） | 中期空头，坚决不进场 |
| 20日线走平 | 0%（观望） | 震荡市，观望为主 |
| MACD+买点+趋势向上 | 30%（上限50%） | 3成仓试探，回踩确认加仓 |
| 金叉+条件满足+趋势向上 | 30%（上限50%） | 首次3成，回踩确认加2成 |
| 回踩买点+趋势向上 | 30%（上限50%） | 确认后买入3成，再加仓 |
| 粘合发散买点 | 40%（上限40%） | 4成仓快进快出 |
| 有信号但条件不满足 | 20%（上限30%） | 轻仓或等待确认 |
| 无明确买点 | 0%（空仓） | 空仓观望 |

#### 3.2.5 风险评估

| 风险等级 | 触发条件 |
|---|---|
| 高风险 (high) | 已触发止损信号，或趋势向下 |
| 中风险 (medium) | 趋势走平 |
| 低风险 (low) | 趋势向上且无止损信号 |

### 3.3 边界情况

- 数据不足（<20个交易日）：提示"数据不足，无法判断趋势"
- 无信号：显示"当前无信号"
- 股票不存在或数据拉取失败：显示错误提示

## 4. 模块三：K 线图表

### 4.1 图表组成

| 元素 | 说明 |
|---|---|
| K 线图 | 红涨绿跌，标准日本蜡烛图 |
| MA5 均线 | 粉色线，5日移动平均 |
| MA20 均线 | 蓝色线，20日移动平均 |
| 成交量柱 | 红色（涨）/ 绿色（跌），在图表下方 |
| 信号标记 | 菱形（策略信号）/ 大头针（回测信号），标注在 K线最高价上方；回测信号标签显示对应策略名称如"买入(金叉)"、"卖出(死叉)" |
| 时间轴缩放 | 滑块 + 鼠标滚轮缩放 |

### 4.2 信号筛选

图表上方提供勾选框，用户可选择显示/隐藏特定类型的信号标记：

- 金叉 / 回踩 / 粘合 / MACD+ / 共振 / 止损MA5 / 止损MA20 / 死叉 / 止盈 / 最小止盈
- 回测买入 / 回测卖出（在运行回测后出现）

### 4.3 交互功能

- 鼠标悬停显示十字光标，展示各指标数值
- 底部的范围滑块可缩放到任意时间段
- 窗口大小变化时自动调整

### 4.4 边界情况

- 无数据：图表区域空白
- 数据极少（<5条）：均线无法显示（NaN 值不渲染）
- 无信号标记：仅展示 K 线和均线

## 5. 模块四：回测验证

### 5.1 回测参数

用户在右侧"回测"选项卡中设置：

| 参数 | 默认值 | 说明 |
|---|---|---|
| 回测策略 | MA520均线策略 | 下拉选择框，从 `/api/strategies` 加载可用策略列表 |
| 时间范围 | 最近1年 | 日期范围选择器 |
| 初始资金 | 100,000 元 | 可设置 1万~1000万 |
| 费率 | 2.5‱ | 每笔交易按成交金额比例收取，可自定义 |
| 保底费用 | 5 元 | 每笔交易最低收取费用，费率为0时保底费用独立生效 |

### 5.2 策略规则展示

选择回测策略后，表单上方同步显示策略详情卡片，分区展示：

| 分区 | 内容 | 颜色标识 |
|---|---|---|
| 买入策略 | 所有买入规则的触发条件和执行动作，按优先级排列 | 红色标签 |
| 卖出策略 | 所有卖出规则的触发条件和执行动作，按优先级排列 | 绿色标签 |
| 加仓策略 | 加仓条件与加仓动作 | 蓝灰标签 |

每条规则格式：`[类型标签] 触发条件 → 执行动作`

### 5.3 回测规则

系统模拟逐日交易，当前内置的 `ma520` 策略规则如下：

**买入信号优先级**：
1. 金叉+MACD+ 双信号共振 → 50% 仓位
2. 金叉（放量+趋势向上+站上均线）→ 30% 仓位
3. 回踩（缩量回踩+带量站上5日线）→ 30% 仓位
4. 粘合发散突破 → 40% 仓位
5. **禁止买入条件**：20日线向下或走平时不进场

**加仓规则**（仅在已持仓时）：盈利状态下趋势向上，加仓 20%（总仓位不超过 50%）

**卖出信号**：
1. 盈利达 10%~20% → 止盈卖出
2. 5日线下穿20日线（死叉）→ 清仓
3. 连续3日收盘跌破5日线 → 止损
4. 放量跌破20日线 → 无条件清仓

**费率**：按用户自定义的费率（默认万分之 2.5）和保底费用（默认 5 元）计算，`费用 = max(成交金额 × 费率, 保底费用)`，费率为 0 时仅收保底费用。

### 5.4 回测结果

运行完成后展示：

| 指标 | 格式 | 说明 |
|---|---|---|
| 最终资产 | ¥xxx.xx | 期末总资产 |
| 总收益率 | +xx.xx% | 总收益率，正值绿色/负值红色 |
| 年化收益 | +xx.xx% | 年化收益率 |
| 最大回撤 | xx.xx% | 从峰值下跌的最大幅度 |
| 胜率 | xx.x% | 盈利交易占比 |
| 交易次数 | x | 总交易笔数（买入/卖出/加仓/平仓合计） |
| 总费用 | ¥xx.xx | 累计手续费 |

**资产曲线图**：
- 蓝色折线：账户总资产变化
- 绿色柱状：持仓股数变化
- 双 Y 轴：左轴资产(¥)，右轴持仓(股)

**交易记录表**：
- 日期 / 操作(买入/卖出/加仓) / 价格 / 数量 / 金额 / 原因

### 5.5 K 线联动

回测结果会在大盘 K 线图上叠加显示：
- 买入/加仓位置标记为绿色大头针，标签显示对应策略名称如 `买入(金叉)`、`买入(共振)`、`加仓`
- 卖出位置标记为红色大头针，标签显示对应策略名称如 `卖出(死叉)`、`卖出(止损MA5)`、`卖出(平仓)`

### 5.6 边界情况

- 数据不足（<20条）：提示无法回测
- 回测期间从未买入：收益率0%，交易次数0
- 回测失败（数据拉取异常）：显示错误信息

## 6. 模块五：金叉筛选

### 6.1 功能入口

首页左侧"金叉筛选"卡片

### 6.2 两种扫描模式

#### 模式一：缓存扫描

- **操作**：点击"缓存扫描"按钮
- **范围**：仅在本地数据库已有数据的股票中扫描
- **特点**：速度快，无需联网拉取新数据
- **适用场景**：快速检查已关注股票的当前金叉情况

#### 模式二：全量扫描

- **操作**：点击"全量扫描"按钮
- **范围**：扫描 A 股全市场（约 5000 只）
- **检测信号**：同时检测 **金叉 (golden_cross)** 和 **金叉+MACD+共振 (combined_gc_macd)** 两种买入信号
- **特点**：每个股票实时拉取近 30 天数据检测信号，耗时较长

**扫描过程中用户可**：
- **暂停/继续**：随时暂停扫描，查看已发现的信号结果
- **跳转**：输入索引数字，快速跳转到指定位置继续扫描
- **清除**：清除当前扫描任务及持久化的结果

**扫描状态反馈**：
- 进度条：`已处理 / 总数`
- 扫描过程中发现的股票实时追加到结果列表
- 每条结果左侧显示信号类型标签：红色"金叉" / 粉色"共振"

**结果展示**：股票代码、名称、信号类型标签、日期、价格、条件说明

**持久化**：扫描结果存入 `localStorage`，关闭窗口或刷新页面后仍可直接查看上次扫描结果，无需重新扫描

### 6.3 边界情况

- 缓存扫描无结果：提示"点击缓存扫描或全量扫描"
- 全量扫描中无金叉：结果列表为空，状态显示 completed
- 网络中断影响扫描：轮训失败自动清理

## 7. 模块六：系统配置

### 7.1 配置入口

顶部导航 → "配置"页面

### 7.2 配置项

| 配置项 | 类型 | 说明 |
|---|---|---|
| 行情源优先级 | 多选排序 | Baostock > Efinance > 同花顺 HTTP > 同花顺 SDK > 新浪 > AKShare |
| 同花顺 HTTP Refresh Token | 密码输入框 | 必填，用于自动刷新 access_token |
| 同花顺 HTTP Access Token | 密码输入框 | 选填 |
| 启用同花顺 iFinD SDK | 开关 | 需本机安装 iFinD 环境 |
| 默认复权方式 | 下拉选择 | 前复权 / 后复权 / 不复权 |

### 7.3 数据源优先级说明

系统按照配置的顺序依次尝试拉取数据，第一顺位失败则自动切换到下一顺位。所有数据源均失败时，尝试返回本地缓存数据。

各数据源特点：

| 数据源 | 需配置 | 优势 | 劣势 |
|---|---|---|---|---|
| Baostock | 无需配置 | 免费、数据齐全 | 需登录/登出操作 |
| Efinance(东方财富) | 无需配置 | 免费、覆盖全 | 依赖东方财富接口 |
| 同花顺 HTTP | 需 refresh_token | 数据质量高 | 需申请 token |
| 同花顺 iFinD SDK | 需安装环境 | 机构级数据 | 部署门槛高 |
| 新浪财经 | 无需配置 | 免费、稳定 | 数据量有限 |
| AKShare | 无需配置 | 免费、覆盖全 | 偶尔限速 |

### 7.4 保存与生效

配置保存后立即写入 `config.json` 文件，下次数据请求时生效。无需重启服务。

## 8. 异常与边界处理总则

### 8.1 网络异常
- API 请求失败：前端抛出错误提醒，不阻塞 UI
- 轮训中断：自动停止轮训，清除无效 scan_id
- 数据源全部不可用：回退到本地缓存

### 8.2 数据异常
- 数据不足：各模块自行判断最小数据量要求（趋势需≥20条，信号需≥27条）
- 复牌/停牌：按自然日处理，不填充缺失日
- 新股：上市不足20个交易日时无法生成均线和信号

### 8.3 操作边界
- 重复插入：自选股/缓存数据均按唯一键去重
- 并发扫描：同一时间仅支持一个全量扫描任务
- 长时间运行：全量扫描为后台线程，不阻塞 API

## 9. 用户操作场景示例

### 场景一：日常复盘
1. 打开系统首页
2. 点击"缓存扫描"查看已有数据中哪些股票出现金叉
3. 在结果中找到感兴趣的股票
4. 搜索该股票，进入策略分析
5. 查看趋势方向、当前信号、仓位建议
6. 参考 K 线图观察均线形态和信号位置

### 场景二：选股验证
1. 点击"全量扫描"扫描全市场，同时检测金叉和共振信号
2. 扫描过程中发现目标，暂停扫描
3. 点击结果中的股票进行分析
4. 切换至"回测"选项卡，设置1年时间范围
5. 运行回测，查看收益率和胜率
6. 参考资产曲线和交易记录评估策略效果

### 场景三：配置调整
1. 获取同花顺 HTTP 的 refresh_token
2. 进入"配置"页面填写 token
3. 将同花顺 HTTP 设为最高优先级
4. 选择前复权为默认复权方式
5. 保存配置后返回首页正常使用
